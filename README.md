# Example of using Zizmor to scan GitHub Actions

This repository contains example workflows to demonstrate how to use [Zizmor](https://zizmorcore.github.io/zizmor/) to scan GitHub Actions for security issues.

## Prerequisites

- Enabled GitHub Advanced Security (GHAS) on your repository.
- Enable dependency graph and Dependabot alerts in the repository settings.

Note: Zizmor can be used without GHAS, check the [Zizmor documentation](https://zizmorcore.github.io/zizmor/) for more information.
